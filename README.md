# companion-module-awtb-cuemaster

[Bitfocus Companion](https://bitfocus.io/companion) module for **CueMaster**, the jingle player for Windows by Advanced Works ([awtb.de](https://www.awtb.de)).

Fire, stop and fade cues, switch banks, control the player and show tile names, colours and remaining time on your buttons.

See [companion/HELP.md](companion/HELP.md) for setup, actions, feedbacks and variables.

## Development

```
npm install
npm test
npm run package
```

Requires Node.js 22. CueMaster 1.0.1 or later with *Companion and Stream Deck (HTTP and WebSocket)* enabled.
